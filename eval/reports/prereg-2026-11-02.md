## 三、主检验与判定

- 方法：McNemar 精确二项检验，**单侧**（改善方向），n=6
- 判定：**b ≥ 5 且 p < 0.05 → 显著**（b=5 → p=0.031；b=6 → p=0.016）
- b ≤ 4：只报通过率差 + Clopper-Pearson 95% CI + 逐题明细，写"**未达统计显著**"
- 统计实现：`eval/stats.py` 的 McNemar 函数，不另写第二份
- 次指标（仅描述）：逐题中位数、k_pass、均分、两臂逐跑 duration_s / token

## 四、选题规则（摸底后执行一次）

1. 摸底：7 道候选 × 3 跑，**仅 A 臂**
2. 入选硬条件：**3/3 全部失败**（`rubric.pass=false`）
3. 多于 5 道 → 取通过次数最少者（同分按题 id 升序）
4. 机制核验：逐题查 3 跑工具序列，失败形态须为"未做价格带筛选（无 price_min/price_max/energy 的 search_cars）就进入车型级对比"；形态不符者剔除并记入归因台账
5. 不足 5 道 → 用现有单元跑完，报告写"有效单元不足，不报 p"
