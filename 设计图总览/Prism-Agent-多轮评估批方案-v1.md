## 1. 背景与动机

- runner 多轮机制（task.turns 依序 POST + session_id 穿线 + 终轮判分 + 逐轮 truth）已交付，**全题库 0 道多轮题 0 单测——基建空转**
- 样本类型缺 4 类：恢复式（用户纠正）/ 取消 / 超时 / 历史失败（博主 12 种对照）
- 6 道低分题的 L1-2 归因需要"首错轮"视图——判分器已逐轮查锚，只差落表
- 用户分析需要表格产物（对齐博主评测数据结果表做法）

## 2. 对标结论（实测，2026-10-15）

| 学习对象 | 做法 | 对本方案的影响 |
|---|---|---|
| τ²-bench（教材仓实测 5 任务轨迹） | 用户轮 11-27（自适应模拟器），失败题轮数反而最多（27 轮） | 长对话是"自适应"的产物；脚本化 27 轮无意义 → 我们 2-4 轮够 |
| 博主五级结构 | Episode=可独立判成败的用户目标，是**核心评分单元**；固定脚本与动态模拟器均合法；**引入模拟器必须连模拟器质量一起评** | 评分单元取 Episode；v1 用脚本化追问不上模拟器（模拟器质量评估留给 v2） |
| 阿里 12 条 #9 | 多轮必须处理 session 时序，否则误诊为记忆问题 | 穿线验证表正是防误诊的取证 |

**右尺寸推导**：6 原型 × 2 = 12 Episode；每 Episode 2-4 轮（真实 PM 追问 2-5 轮收敛）；成本 ≈30 次 agent run ≈ 6-12M tokens（单题均 ~20 万 token 实测外推）。

## 6. 分析方法（用户侧怎么看）

1. **逐轮衰减表**：t2 掉锚而单轮重问能对 → 上下文延续问题实锤（防"误诊记忆"）
2. **恢复成功率**：附和率 >0 → 提示词层要加"用户纠正≠真相，仍以工具真值为准"
3. **穿线验证**：t2 凭上下文报价不重查 → 上下文偷懒，考虑强制复读工具口径
4. 轨迹：langfuse(3000) → environment=eval → 搜题号，同一 session_id 串起全轮

## 10. v1.1 增补（2026-10-16）：三个增量机制——不上 τ²-bench，偷它的魂

> 定位：脚本化与 LLM 模拟器之间的中间形态。三机制都是 runner/schema 增量，**不动判分主干**；追问答复确定性保持（同题同答同路径）。机制①③的 turns 新字段与既有 `turns=[{message,truth?}]` 向后兼容（旧格式照跑）。

### 机制①：条件分支追问（规则版渐进透露——τ²-bench known_info 的精神）

```json
{ "branch_on": "t1",                       // 依据第 1 轮 truth 判定选分支
  "if_hit":  { "message": "那和 B10 比呢？", "truth": { "anchors": [...] } },
  "else":    { "message": "你确定吗？我再问一次", "truth": null } }   // 压力路径：答含糊→追问到底
```

runner 判完该轮逐轮 truth 后选分支。覆盖"看答下菜"的交互（agent 答得含糊就走追问到底路径），成本 = runner +15 行。

### 机制②：话术池轮换（顶住率的措辞鲁棒性机制化）

```json
{ "message": { "variants": ["你说错了", "是不是搞错了呀", "我看到的数不一样"] },
  "variant_by": "repeat" }   // --repeat=k 时取 variants[(k-1) % n]——三跑覆盖三种语气
```

硬纠正/软诱导/数据对抗三类话术各进池子；`--repeat=3` 一次批跑即得"顶住率×语气"矩阵。**§9 原开放项"语气软硬影响"就此收编。**

### 机制③：穿线验证机械版（轮间一致性锚——Sheet4 从占位变实值）

```json
{ "carry_anchor": { "from": 1, "keys": ["4436"] } }   // 轮 1 结论的关键数字
```

判分器对 from 之后的轮次查 keys：**复现时必须同值**（出现不同值 → `truth[tN] 轮间漂移: t1=4436→tN=4437`，进 reasons 拉低终分）；不复现不查（不提旧数字不算错）。渲染层 Sheet4 的 `t2_ref_t1` 列由"待轨迹分析"占位变为"一致/漂移(值)"实值（report_lib crossCheckRows 小改）。**上下文漂移从此可判分器直出，不依赖人工读 langfuse。**
