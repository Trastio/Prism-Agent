北极星三层（2026-09-30 拍板·修正原"单位成本正确率"错位）：原"单位成本正确率"是输入指标不是北极星——驱动 agent 质量但讲不清"Prism 成了没"。问题6三处不一致根源就是把它当北极星用，现分清三层：

商业北极星：日活量 DAU（看板 DAU + 对话 DAU 分开算）+ 在线时长（活跃时长，看板/对话分开算）。用途：项目存续判断。内部工具价值=融入日常工作流，"每天在用"=存活最直接信号，可日度量、可设阈值。看板 DAU=每天至少打开一个 BI 看板页的独立本地 ID 数；对话 DAU=每天至少发起一次 agent 对话的独立本地 ID 数。总 DAU=两者去重。在线时长（2026-10-06 增列）：DAU 只看"来没来"（广度）不够，在线时长看"待多久/用多深"（厚度）——每个本地 ID 每天在前端"页面可见且活跃"下的累计秒数，看板/对话分开。采集=Page Visibility API + 心跳（可见时每 30s 累加，切后台/关闭用 sendBeacon 补尾）；刻意不用 SSE 会话时长（长分析单轮可达 25min，会虚高失真）。

产品北极星（主指标）：周成功交付结论数——一周内 agent/看板产出的、被用户采纳（未点踩未撤销）的结论绝对量。看板和 agent 双模式都计入。绝对量非比率：40人工具型产品，用的人多不多是第一位，比率看不出使用深度；"被采纳"过滤编造结论，"结论数"绑使用深度。起步可先用"周活×平均结论采纳率"过渡，跑通后升级绝对量。

输入指标（驱动迭代）：Pass^1 × (1−幻觉率) ÷ 单次成本 · WAU · 人均结论数 · 采纳率 · 响应时延。原"×零幻觉"改为"×(1−幻觉率)"（严格为0则乘积恒0不可计算）。上线后 API 费用随使用量上升，成本分母有区分度，保留在输入层。

由此推导：③评估测"结论正确率+数字溯源通过率"（喂输入指标）；④埋点埋"结论产出事件+用户采纳/点踩"（喂产品北极星）；⑥反馈驱动"用户纠正率下降趋势"；⑧复盘看"边界集通过率+保留集不退化+纠正率下降"（发版门槛，非北极星本体）。

已定调判断（后记叙事框架）

Agent = LLM + 上下文 + 工具。模型会吃掉Harness，但一层一层吃，永远吃不完——训练以月计、业务等不起；不换模型只改harness，准确率52.8%→66.5%。

"用harness争取时间，用这段时间构筑技术之外的壁垒"。Prism护城河不在harness本身（迟早被抹平），而在：汽车领域独占数据源 + 口碑/销量/配置交叉验证口径 + "做对了但说错了"静默失败的失败归因资产。

北极星三层（v2.4·2026-10-02 商业改 DAU）

商业北极星
日活量 DAU + 在线时长（看板/对话分开）

内部工具价值=融入日常工作流，"每天在用"=存活最直接信号。看板 DAU（打开看板页）+ 对话 DAU（发起对话）分开算，总 DAU 去重。2026-10-06 增列在线时长（活跃时长）：每个本地 ID 每天的"页面可见且活跃"累计秒数，量"待多久/用多深"，与 DAU（来没来）合成完整存续信号。均埋点可算。

产品北极星（主指标）
周成功交付结论数

被采纳（未点踩未撤销）的结论绝对量。看板和agent双模式都计入。绝对量非比率——40人工具型产品用的人多不多是第一位。起步可先用"周活×平均结论采纳率"过渡。

输入指标（驱动迭代）
Pass^1×(1−幻觉率)÷单次成本 等

WAU/人均结论数/采纳率/响应时延。原"单位成本正确率"归这层——驱动agent质量迭代，不是北极星本体。上线后成本分母有区分度。

发版门槛（非北极星）
边界集通过率+保留集不退化+纠正率下降

评估四环节服务"这个版本该不该发"。这是发布门不是北极星本身；之前与北极星混写系表述错位，v2.2 分清。
