# hermes-agent 看板栏 · 品牌与视觉契约

**一句话**：沿用 hermes-agent 现有的「米白画布 + 单一主蓝 + 高对比 Didone 衬线」语言；看板栏只做一件事——把四个板块组织成一条常驻的一级切换条，其余界面保持安静。

品牌来源：用户提供的界面截图 `屏幕截图-2026-10-04-002344.png`（像素取样，非估算）。

## 字体栈

- Display：`"Bodoni Moda", Didot, "Bodoni MT", Georgia, "Songti SC", "SimSun", serif` —— 对齐截图中 HERMES AGENT 的高对比 Didone 字型，仅用于拉丁小标与品牌字。
- Body / UI：`"PingFang SC", "Microsoft YaHei", "Noto Sans SC", system-ui, -apple-system, "Segoe UI", sans-serif`
- Mono：`ui-monospace, SFMono-Regular, Consolas, monospace` —— 仅用于指标数字与时间戳。

## 视觉规则（5 条）

1. 画布恒为米白、卡片恒为纯白 + 1px 描边；层级靠间距与字重，不靠阴影堆叠。
2. 主蓝每屏最多两次：看板栏选中项 + 当前看板唯一主操作（「保存配置」）。图表使用派生蓝 `--chart`，不占用主蓝配额。
3. 中文标题 `letter-spacing: 0`、行高 ≥ 1.35；仅拉丁大写小标使用 `0.16em` 字距、0 负字距。
4. 图标统一 1.7px 描边、`currentColor`、无填充色块。
5. 监测型板块（舆情 / 市场 / 口碑）用卡片 + 填充图表；控制型板块（配置）用分组表单，并在看板栏中以竖线分隔，避免语义混淆。
