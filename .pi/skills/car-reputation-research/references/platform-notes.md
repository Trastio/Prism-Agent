# 平台可用性与抓取经验（Prism 版 · 2026-10 实测）

社媒抓取全部走 TikHub 工具（免登录、结构化 JSON、按调用计费）；汽车之家走 web 抓取（游客全通）。反爬策略与 API 字段随时变，用前先小样验证。

## TikHub（social_* 工具）

- 输出信封：`items[]` 每条带 `url`（引用必带）+ `_meta{as_of, 不可复算:true}`（引用必声明）
- 搜索：抖音/小红书/微博/快手/哔哩；时间窗参数平台支持不一致，不支持自动忽略
- 评论：评论区是购车细节金矿——车主自述落地价/配置/颜色/有无现车/补贴细节，且常有与网友的一手对话；信息密度常高于正文
- 用户画像/作品：仅抖音+小红书。抖音画像支持三种标识：sec_uid（MS4wLjAB…）、用户主页链接、纯数字抖音号；**作品列表必须 sec_uid**（拿抖音号先 social_user_profile 换查）
- 抖音视频页发布时间精确到分，是日期实锤的最佳来源（口述日期常误记，以此校正）
- IP 属地/年龄线索可拼用户画像，但推不出的一律标"无实锤"（铁律#7：人群理解颗粒度）
- 计费护栏：每轮 8 次上限；搜索词先精准后泛化；视频统计批量接口比逐条便宜

## 汽车之家（web 抓取）

- 游客全通：论坛、口碑、车友圈直接访问，无需登录
- 帖子 URL 格式：`club.autohome.com.cn/bbs/thread/{hash}/{topicid}-1.html`（hash 是十六进制串，topicid 是数字）
- 老账号KOC发帖质量高（长决策帖、成交帖），值得单独立案深挖
- 论坛"车友数/帖子数"可作声量基数记录（如"上市1周72车友/523帖"）
- 注意：论坛主帖不在 Prism 库内（库里是口碑体系 owner_reviews，33 车系池）——论坛内容只能 web 抓，引用标 URL 不可复算

## B站

- social_search(bilibili) 或 web 兜底均可
- 新车个人提车作业少，注意同系列标题（如"终于轮到我"）混入其他车型，按车型名过滤

## 通用

- 短时间密集抓取注意节奏（TikHub 有 rate limit，约 10/秒/端点）
- 平台"内容不存在"提示不一定是真不存在，可能是端点参数形态不对——换平台或换标识再试
- 懂车帝不做（搜索强制登录，内容与汽车之家高度重叠）
