核心技术

不只是 API 调用，而是完整的 ML + 数据工程

从模型微调到采集引擎，从事件追踪到可视化看板——每个环节都有具体的工程落地手段。

模型微调

Qwen3-4B ABSA 方面级情感分析微调

从零构建汽车评论 ABSA 数据集，基于 Unsloth + QLoRA 对 Qwen3-4B 进行参数高效微调：

  • 数据集构建：爬取汽车之家 NEV 口碑 + BDCI2018 油车评论，LLM 标注 → 维度×情感平衡采样 → 混合通用指令，产出 1,297 条高质量样本
  • 训练配置：4-bit 量化 + LoRA r=16，最佳 checkpoint eval_loss 降至 0.82
  • 推理效果：15 维度情感命中率 83%，本地 GPU 推理峰值显存仅 5GB
采集引擎

7 平台采集 + 多层质量控制

集成 OneAPI 转售接口覆盖主流社媒，搭配自研质量控制管道：

  • 关键词扩展：LLM 从新闻标题自动生成搜索别名，首次采集后缓存复用（7 天过期）
  • 全文抓取：Trafilatura 两级策略（URL 正文提取 + 降级 snippet）
  • 去重与过滤：SimHash 64 位指纹去重（Hamming ≤ 3）+ 品牌关键词白名单
  • 评论独立存储：Top5 热帖半月窗口批处理总结
事件追踪

17 类事件标签 + 密度聚类 + 异常检测

从离散帖文中自动识别事件脉络，实时预警异常声量波动并给出根因解释：

  • 事件标签池：17 类预定义（质量问题/安全事故/降价促销/OTA升级/维权投诉等）
  • DBSCAN 聚类：eps=7 天窗口，自动合并同类事件形成时间线
  • 异常检测：日声量变化 ±60% 触发告警，自动关联事件标签分布生成根因
  • 热度指标：综合 attention_index（搜索指数）、discussion_volume、interaction_intensity
可视化看板

Vue 3 + ECharts 实时交互看板

纯前端 CDN 架构，零构建工具依赖，支持车型搜索、分组对比、对话追问：

  • 全局时间选择器：日/周/月 + 自定义范围，所有图表联动刷新
  • 情感环形图 + 趋势折线 + 事件时间线 + 词云：一屏全览
  • 异常告警条：滚动显示 ±60% 声量异动，标注事件类型和根因
  • SSE 流式对话：锚点上下文 + 图表元素点击追问，支持多轮
  • 分组对比：多车型趋势叠加 + 维度雷达图

核心能力

为品牌舆情监控深度定制

多平台并发采集

OneAPI 接口集成小红书/微博/抖音/快手四平台 + 8 个新闻源 API。平台策略模式控制调用配额、请求间隔和评论采集范围。

LLM 关键词扩展

首次采集时从新闻标题中自动提取品牌别名和车型昵称（如"海狮05 EV" → "海狮05/海狮/比亚迪海狮"），缓存 7 天复用，扩大搜索召回率。

双模型并行分析

自微调 Qwen3-4B（15 维度情感 + 主体识别）+ GLM-4-Flash（17 类事件 + 观点标签）。asyncio.gather 并行调用，结果合并写入 AnalyzedPost。

事件自动聚类

从事件标签共现矩阵构建关键词图，Louvain 社区发现 + DBSCAN 密度聚类（eps=7d），自动追踪事件从爆发到消退的完整脉络。

异常声量检测

滚动窗口计算日声量基线，当日声量变化 ±60% 触发 anomaly_event。自动关联 Top 事件标签分布，生成"What happened"根因解释。

实时看板交互

Vue 3 CDN + ECharts 构建 v5 看板：全局时间选择器控制所有图表范围，情感环形图、趋势折线、事件时间线、词云、异常告警条一屏全览。

SSE 流式对话

FastAPI + SSE 实现锚点上下文对话，用户点击图表元素后可直接追问（如"为什么上周负面激增？"），Agent 自动关联相关帖文和事件数据回答。

车型分组对比

支持自定义车型分组，一键对比多款竞品的舆情趋势、情感分布和维度雷达图。分组概览卡片显示各车型舆情总量和正/负/中分布。
