方法论 · Methodology

数据来源：TikHub 接口（小红书 / 抖音 双平台社媒）+ 车质网投诉直采；微博 / 快手 / 新闻源自 2026-10 起停采（历史存量仍展示）。

分析管线：帖子 → GLM-4-Flash API 一站式（sentiment / dim_sentiment / event_tags / opinion_tags / subject 标注）（维度轴由帖子侧承载）；评论 → 极性直出（正/中/负，DeepSeek v4-flash；2026-10-20 前为本地 Qwen3-4B，跨引擎趋势不作对比）；事件聚类 → LLM 标注 → jieba 关键词 → 共现图 → Louvain 社区检测 → LLM 命名。

健康分：50 +（正面 − 负面）/ 总量 × 50，仅计算主车型帖（subject = self），并排除官方账号与经销商作者（author_type 过滤，2026-09-15 起）。

搜索热度：抖音 / 小红书搜索指数各自按窗内峰值归一（各平台峰值 = 100）后同轴展示，仅反映搜索行为，非讨论量。

发酵话题追踪：仅取社媒事件聚类（新闻事件已剔除），按窗内帖量排序；触发原因取聚类摘要，当前热度取窗内帖量、持续取起止跨度。传播路径（话题标签复用 / 跨平台扩散 / KOL 参与度）与互动增速尚未入库，不作推断。
