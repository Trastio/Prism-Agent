## 三、分情形操作（按体检结果对号入座）

### 情形A：项目内含 MediaCrawler（目录里有 `MediaCrawler/` 或 `config/base_config.py`）

1. **改关键词**：编辑 `config/base_config.py`（若在MindSpider内则路径为 `MindSpider/DeepSentimentCrawling/MediaCrawler/config/base_config.py`）：
   - `KEYWORDS = ["风云T7", "奇瑞风云T7", "风云T7提车", "风云T7试驾", "风云T7缺点", "风云T7续航"]`
   - `ENABLE_GET_COMMENTS = True`（**默认关闭**，务必打开，否则抓不到评论）
   - `CRAWLER_MAX_NOTES_COUNT = 30`（先小量测试）
   - `HEADLESS = False`（首次登录必须能看到浏览器界面）
2. **推荐CDP模式**（风控更少）：Chrome地址栏输入 `chrome://inspect/#remote-debugging` 勾选 "Allow remote debugging"，显示 `Server running at 127.0.0.1:9222` 即就绪
3. **逐平台登录+试爬**（每个平台首次都要扫码，登录态会缓存到 `browser_data/`）：
   ```
   uv run main.py --platform xhs --lt qrcode --type search   # 小红书（最优先：上轮空白最大）
   uv run main.py --platform dy  --lt qrcode --type search   # 抖音（需Node.js>=16）
   uv run main.py --platform ks  --lt qrcode --type search   # 快手
   uv run main.py --platform wb  --lt qrcode --type search   # 微博
   uv run main.py --platform zhihu --lt qrcode --type search # 知乎
   uv run main.py --platform bili --lt qrcode --type search  # B站
   ```
   （无uv则用 `python main.py ...`）
4. **数据在哪**：默认输出 csv/json 到 `data/` 目录（`SAVE_DATA_OPTION` 可改 excel/sqlite/mysql）

### 情形B：项目是 BettaFish(微舆) 全栈（目录里有 `QueryEngine/InsightEngine/ReportEngine/MindSpider` 等）

1. 配置 `.env`（复制 `.env.example`）：数据库（DB_DIALECT=postgresql 或 mysql + 连接信息）+ 各Agent的LLM API（OpenAI兼容格式：KEY/BASE_URL/MODEL_NAME）
2. 依赖：`pip install -r requirements.txt` → `playwright install chromium`
3. 启动主应用：`python app.py` → 浏览器开 `http://localhost:5000`
4. 爬虫单独跑（在项目根目录）：
   ```
   cd MindSpider
   python main.py --setup          # 初始化
   python main.py --deep-sentiment --platforms xhs dy wb --test   # 先测试
   python main.py --deep-sentiment --platforms xhs dy ks wb zhihu bili  # 正式
   ```
   注意：MindSpider的关键词默认由AI从每日热点自动提取；**要爬风云T7这种固定主题，请直接用它内嵌的MediaCrawler**（`MindSpider/DeepSentimentCrawling/MediaCrawler/`，按情形A操作KEYWORDS）
5. 生成报告：Web界面提问"奇瑞风云T7品牌声誉分析"，或命令行 `python report_engine_only.py --query "风云T7品牌舆情"`（输出到 `final_reports/`，含企业品牌声誉分析模板）

## 五、常见问题

| 问题 | 解法 |
|---|---|
| 二维码不显示/登录卡住 | `base_config.py` 里 `HEADLESS = False`；删 `browser_data/` 目录重登 |
| 爬取数据为空 | 确认平台已登录、KEYWORDS已保存、先用 `--test` 验证 |
| playwright报错 | `playwright install chromium`；抖音/知乎还需Node.js ≥ 16 |
| 端口被占用（上次异常退出） | 任务管理器结束残留的 python/streamlit 进程 |
| 抖音/快手风控提示 | 用CDP模式连接日常Chrome（复用真实登录态），控制频率、小量多次 |
