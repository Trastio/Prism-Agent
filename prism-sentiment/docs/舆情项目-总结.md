# 车型舆情情感分析看板 —— 项目总结

> 截至 2026-09-13。架构细节见《[项目架构](舆情项目-架构.md)》，本文讲清：

---

## 1. 项目概况

**单机自包含的车型舆情监测系统**：对指定车型（当前 5 款）自动采集微博/小红书/快手/抖音/新闻
五路内容，LLM+本地模型做情感与维度分析、事件聚类、热度聚合，Vue 单页看板四层递进展示
（KPI → 趋势 → 归因 → 内容），支持锚点对话与舆情报告。

- 技术栈：FastAPI + SQLite + Vue3(CDN) + GLM(云 LLM) + Qwen3-4B LoRA(本地 ABSA)
- 规模：317 commits、**647 测试全绿**、10 张表、6 家外部供应商
- 运行形态：`start.py` supervisor 常驻 :8000，`daily_update.py` 单命令日更

## 2. 核心架构（一图版）

```
采集(TikHub/OneAPI/anspire/bocha, 5词×4平台+新闻+双平台指数, 备胎自动回退)
  → 入库(四道去重闸: URL路径/新闻标题/评论cid/simhash; 品牌词+营销号过滤)
  → 分析(GLM帖情感+subject / 本地ABSA评论维度 / jieba+Louvain事件+切片合并)
  → 聚合(每日热度幂等重算 / 双平台指数归一合成0-100)
  → API+看板(四层递进 + 数据积累期提示 + 锚点对话)
```
