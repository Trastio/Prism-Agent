# 车质网（12365auto.com）接入调研

> 调研日期：2026-09-27 ｜ 任务 T1.3（A5）—— 质量投诉主阵地采集

## 1. 结论

**可行，已接入。** 车质网 BBS 按车系分版块，列表页 server-rendered HTML 直出，
无需登录、无验证码、无 JS 渲染依赖，可稳定爬取。

## 2. 调研过程

### 2.1 是否有公开 API？
**无。** 车质网无公开/开放 API。主站 `/server/forBug.ashx` 是投诉提交接口
（用户填表投诉用），非列表查询。BBS 走 aspx 后端。

### 2.2 反爬强度
**极低。** 实测：
- 首页、列表页、详情页均 HTTP 200，无验证码、无 IP 封禁、无 Cloudflare。
- 列表页直出 HTML（UTF-8，18KB/页），帖子链接在 `<a href>` 中。
- 详情页正文在 `<div class="neirong">` 容器内，server-rendered。
- 唯一限制：详情页并发抓取需控制在 3 并发以内（20 并发实测 16 失败，
  非封禁而是服务器连接拒绝，降并发后 20/20 成功）。

### 2.3 页面结构与 URL 模式

| 用途 | URL 模式 | 编码 |
|------|---------|------|
| 车系投诉列表 | `https://bbs.12365auto.com/seriesforum/{seriesID}-{sort}-{page}-{filter}.shtml` | UTF-8 |
| 帖子详情 | `https://bbs.12365auto.com/threadforum/{YYYYMMDD}/{id}.shtml` | UTF-8 |
| 投诉提交 | `https://www.12365auto.com/bug`（forBug.ashx） | — |
| 主站资讯 | `https://www.12365auto.com/parts/{YYYYMMDD}/{id}.shtml` | GBK |

- 列表 URL 参数：`sort=1` 按时间倒序；`page` 从 0 起；`filter=0` 全部。
- seriesID 来自 `brandsHaveSeries.js`（车质网车系 ID 映射表）。

### 2.4 seriesID 映射（项目在监车型）

seriesId 可在车质网车系页 URL 或 `brandsHaveSeries.js` 中查找。

## 3. 实施详情

### 3.1 ChezhiwangCollector
- 文件：`pipeline/collectors/chezhiwang_collector.py`
- 按车系 seriesId 抓列表页（最多 3 页）+ 详情正文（并发限 3）。
- 入库 `platform="chezhiwang"`, `source="chezhiwang"`。
- 字段与 NewsCollector 对齐：title/content/url/author/published_at/source/platform/full_content。

### 3.2 平台注册
- `pipeline/platforms.py`：新增 `CHEZHIWANG = "chezhiwang"` 常量与标签「车质网」。
- `pipeline/collectors/platform_strategy.py`：新增策略（risk=none, max_pages=3）。
- `api/pipeline_state.py`：进度跟踪注册 chezhiwang 平台。

### 3.3 调度器接线
- `pipeline/scheduler.py`：新增 `_collect_chezhiwang` 方法，
  在 `collect_vehicle` 的新闻源采集之后、社媒采集之前执行（Step 1b）。
- 投诉帖进 `all_posts`，经品牌关键词白名单过滤后入库 `raw_posts`，
  进入缺陷监控评论池。

## 4. 价值

车质网投诉帖是缺陷监控的**种子数据**：每条帖子是一起真实车主故障投诉
（尾灯开裂/轮毂氧化/AEB 失效/转向卡滞…），天然就是缺陷话题。接入后：
- 缺陷话题监控（defect-theme）有稳定的高质量输入源。
- 质量投诉与社媒口碑互补：社媒反映用户情绪，车质网反映具体故障模式。
- 投诉帖正文完整（非碎片化评论），利于 LLM 缺陷判读。

## 5. 限制与后续
- seriesID 映射为手动维护，新增车型需补表。
- 仅采集主楼正文，BBS 楼层回复（其他车主附议）未采——量小，后续可补。
- 投诉帖无点赞/转发指标，likes/comments/shares 置 0。
