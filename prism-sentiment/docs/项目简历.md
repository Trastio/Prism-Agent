## 汽车舆情智能分析平台

**技术栈：** Python · FastAPI · Unsloth/TRL · QLoRA · Transformers · SQLAlchemy · Vue 3 · ECharts · MediaCrawler

**项目简介：** 面向新能源汽车品牌的舆情监控平台，覆盖 7 大社媒平台数据采集，通过双模型并行架构实现维度级情感分析，支持异常预警、事件聚类与可视化看板。端到端独立完成全栈开发，351 项测试全部通过。

**模型微调（ABSA 方面级情感分析）：**
- 从零构建汽车评论 ABSA 数据集：爬取汽车之家 NEV 口碑 + BDCI2018 油车评论，经 LLM 标注 → 维度×情感平衡采样 → 混合通用指令数据，最终产出 1297 条高质量样本（15 维度 × 3 档情感）
- 基于 **Unsloth + QLoRA** 对 Qwen3-4B 进行参数高效微调（4-bit 量化 + LoRA r=16），最佳 checkpoint eval_loss 降至 0.82，维度情感命中率 83%，本地 GPU 推理峰值显存仅 5GB
- 微调后模型作为本地推理通道处理 sentiment + dim_sentiment，与 GLM-4-Flash API（事件标注 + 观点提取）并行调用，双模型结果合并写入

**数据采集与质量控制：**
- 集成 **MediaCrawler**（CDP 模式 + QR 登录）覆盖抖音/小红书/B站等 7 平台，增量采集 + 全文抓取（Trafilatura 两级策略），SimHash 64 位指纹去重（Hamming ≤ 3）
- 设计 LLM 关键词扩展机制：首次采集时从新闻标题自动生成搜索别名，后续复用；评论独立存储 + Top5 热帖半月窗口批处理总结

**分析与可视化：**
- 17 类预定义事件标签池 + DBSCAN 密度聚类（eps=7d）实现事件脉络追踪，异常声量检测（±60%）自动关联事件标签分布生成根因解释
- Vue 3 CDN + ECharts 构建 v5 看板：全局时间选择器、情感环形图、卡片式帖子、事件时间线、词云、异常告警条；锚点上下文对话（SSE 流式）支持图表元素点击追问
- FastAPI 异步后端，SQLAlchemy async + SQLite，12 张表完整数据模型，7 个路由模块
