# 配置参数（env 覆盖）

本项目的可调参数已统一收口为「env 覆盖 + 代码默认」模式：未设 env 时取代码
默认值，设了同名 env 整数则覆盖。统一读取入口为 `utils/config.py::env_int`
（字符串用 `env_str`），各模块 `from utils.config import env_int` 后写成

```python
_PARAM = env_int("PARAM_ENV_NAME", default_value)
```

## 读取时机

- **模块级常量**（如 `_CRAWL_CONCURRENCY = env_int(...)`）：在 **import 时**
  定型，之后不再读取 env。运行时调整需重启进程；测试中可用
  `monkeypatch.setattr(module, "_PARAM", new)` 直接改模块属性。
- **函数内调用**（如 `comment_max_pages()`、`batch_runner.comment_top_n()`）：
  每次**调用时**读取 env，测试可用 `monkeypatch.setenv(...)` 动态覆盖。

下文「时机」列标注每参数的读取时机。

## 用法示例

```bash
# 临时调大评论补抓选帖数
COMMENT_TOP_N=30 python start.py

# 临时降低采集并发
CRAWL_CONCURRENCY=2 python start.py

# 临时放宽缺陷簇准入（实验性，可能引入噪音）
DEFECT_MIN_CLUSTER_COMMENTS=5 python start.py
```

## 注意事项

1. **非法值回退默认**：env 设为非整数（如 `abc`、空串）时 `env_int` 回退默认值，
   不抛异常——便于运维试错，但请勿依赖此行为静默吞错。
2. **import 时定型的参数**改 env 后必须**重启服务**才生效；热更新不支持。
3. **成本影响**：调大 `COMMENT_TOP_N` / `COMMENT_MAX_PAGES` / `TIKHUB_*_LIMIT`
   会直接增加 API 计费，参考 `docs/采集方案与频率.md` 的成本估算。
4. 新增可调参数时，请走同一模式：`from utils.config import env_int` +
   模块级 `env_int("NEW_PARAM", default)` + 在本表登记。
