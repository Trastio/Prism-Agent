### D2. 快手内容数据停滞

**问题**：KS最新文件停在05-31，可能已被连续失败机制跳过

**方案**：
1. `media_crawler.py` — 增加每日自动重置机制：在 `_should_skip()` 中加入过期判断
```python
def _should_skip(self, platform: str) -> bool:
    failures = self._consecutive_failures.get(platform, 0)
    if failures >= _MAX_CONSECUTIVE_FAILURES:
        # 超过24小时自动重置，给一次重试机会
        last_fail_time = self._last_failure_time.get(platform)
        if last_fail_time and (datetime.now() - last_fail_time).total_seconds() > 86400:
            logger.info("Auto-resetting failure counter for %s after 24h", platform)
            self._consecutive_failures.pop(platform, None)
            self._last_failure_time.pop(platform, None)
            return False
        return True
    return False
```
2. 新增 `_last_failure_time: dict[str, datetime]` 字段
3. `_record_result` 中记录失败时间

**涉及文件**：`pipeline/collectors/media_crawler.py`

**工作量**：0.5h

### D10. 关键词扩展定期更新

**问题**：扩展后永不更新

**方案**：加时间戳判断，7天后可重新扩展

```python
# scheduler.py _expand_keywords_if_needed
async def _expand_keywords_if_needed(self, vehicle: Vehicle) -> list[str]:
    keywords = json.loads(vehicle.search_keywords) if vehicle.search_keywords else [vehicle.name]

    # 已有扩展关键词且未过期（7天内）
    if vehicle.expanded_keywords and vehicle.keywords_expanded_at:
        try:
            expanded_at = datetime.fromisoformat(vehicle.keywords_expanded_at)
            if (datetime.now() - expanded_at).days < 7:
                return json.loads(vehicle.expanded_keywords)
        except (ValueError, TypeError):
            pass

    # 重新扩展
    news_result = await self._session.execute(
        select(RawPost.title).where(RawPost.vehicle_id == vehicle.id).limit(20)
    )
    titles = [row[0] for row in news_result.all() if row[0]]
    expanded = await expand_keywords(vehicle.name, keywords, titles)
    if len(expanded) > _MAX_EXPANDED_KEYWORDS:
        expanded = expanded[:_MAX_EXPANDED_KEYWORDS]
    vehicle.expanded_keywords = json.dumps(expanded, ensure_ascii=False)
    vehicle.keywords_expanded_at = datetime.now().isoformat()  # 新字段
    await self._session.commit()
    return expanded
```

需要给 Vehicle 模型增加 `keywords_expanded_at` 字段（数据库迁移）

### D14. 全文抓取增加重试

**方案**：增加1次重试

```python
# full_text_crawler.py
async def crawl_full_text(url: str, snippet: str, retries: int = 1) -> dict:
    for attempt in range(retries + 1):
        try:
            result = await asyncio.wait_for(_do_crawl(url), timeout=10)
            if result:
                return {"full_text": result}
        except Exception:
            if attempt < retries:
                await asyncio.sleep(1)  # 重试前等待1秒
                continue
    return {"full_text": snippet}
```
