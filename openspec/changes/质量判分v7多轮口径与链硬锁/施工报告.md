## 关键决策 / 与 proposal 的偏离

1. **末轮行格式**：proposal 示例"第 {n} 轮（最后一轮）"（带空格）实现为"第3轮（最后一轮）"（统一无空格）——
   语义等价、格式统一；两轮题即退化为拍板最小形态"首轮+末轮"。
2. **中间轮问题一并给全**：proposal D1 明文"超集实现"允许，非偏离，此处留痕。
3. **{turns} 最后填充 + 非字符串轮项剔除**：proposal 未规定的脏数据防护，自加。
4. **已知残余注入面**：多轮型 reply_full 含字面 `{turns}` 会被轮次清单替换（单轮型 v6 同类面本就存在，
   机器生成报告行实际风险≈0）——记录不修。
5. **后置只读槽键=QUALIFIED 全链串**：若未来链多模型而某次实际判分链短（探测剔除），只读会保守报缺槽
   要求重跑全量判——宁保守勿误读，记录。
6. **last_run.mode 恒 'full'**：post/find-gap 不再写 sidecar 的直接后果。旧 ops 脚本
   （logs/quality-watchdog.mjs / quality-v14-retry.mjs）的调用序列=先裸跑全量判→再 --post/--find-gap，
   在 v7 语义下恰好是正确形态，**兼容无需改**（它们读进程输出而非 sidecar.last_run）。
