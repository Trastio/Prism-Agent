# 交互审查发现（2026-10-04 模拟用户交互）

> 通过 CDP 自动化模拟用户操作，逐个测看板/对话/工具调用

---

## 已发现的问题

### 问题 1：白名单过严 → agent 跟护栏打架（已知，根因已分析）
- **现象**：agent 调 write/edit/fetch_content/bash 全被 block，反复尝试
- **根因**：白名单只放 7 个只读工具，红线#2 被错误放大为"禁所有写工具"
- **影响**：闲聊问题（"你具备什么能力"）agent 花大量时间尝试被拦工具
- **修法**：改成行为级拦截（允许所有工具，只拦裸SQL+敏感文件+数据库直连）

### 问题 2：完成验证器太激进 → 闲聊触发"缺证据"
- **现象**：agent 回答"你好，我是谁"后被验证器判定"缺 supported_by 证据"，触发 sendUserMessage retry
- **根因**：验证器检查所有 agent_settled 的回复是否含证据行 ID，闲聊不含就 fail
- **影响**：agent 被迫重新回答，浪费 token + 用户等待
- **修法**：只对"分析类"结论触发验证（检测回复是否含数字/车系名/维度词），闲聊放行

### 问题 3：thinking_delta 没渲染 → 用户看不到 agent 在想什么
- **现象**：agent thinking 30-60 秒，前端只显示"思考中…"，无进度
- **根因**：ChatView 只处理 text_delta，不处理 thinking_delta
- **影响**：用户以为卡死
- **修法**：ChatView 加 thinking_delta 渲染（可折叠的思考区）

### 问题 4：工具活动面板不显示被拦的工具
- **现象**：agent 调工具被 block，前端工具活动面板显示空
- **根因**：tool_call hook block 后 pi 可能不发 tool_execution_start/end 事件
- **影响**：用户不知道发生了什么
- **修法**：mapEvent 加 tool_call block 事件透传

### 问题 5：CDP eval 中文编码损坏（测试工具问题，非产品 bug）
- **现象**：CDP eval 注入中文变成 U+FFFD 乱码
- **根因**：CDP proxy HTTP POST 传输中文编码问题
- **影响**：自动化测试受限，用户手动输入不受影响
- **修法**：测试用英文或用文件注入
