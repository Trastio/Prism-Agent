## 三、判读门槛裁决（按预注册三段走）

- "Δ(A0−B1a)≥1.0 且 trap 差 ≥40pp → 护栏必要性成立"：❌（Δ 为负、trap 差≈0）。
- "Δ<0.3 → 取代论成立"：字面 Δ=−0.71 落入，但分数通道已被 §二.1 证明结构性失真——**不采字面裁决**，按预注册第三段走分层记账。
- **分层记账（护栏价值按题型归位）**：
  1. **trap 拦截、防编造 = 非护栏独占价值**。AGENTS.md 文字纪律进 SKILL 即得 93-100% trap + 零编造。预注册最看好的两道防线，提示词层就够（注意挑战者的 SKILL=AGENTS.md 原文，故准确表述是：**防线价值来自"纪律文字存在"，非执行层闸门**）。
  2. **不可替代①：数据通道**。sentiment-03/04/05 两臂恒 2 分（舆情库无工具结构性不可达）、skill-01 恒 0——口径手册救不了没有的数据。
  3. **不可替代②：口径执行化**。SKILL-B 手册只救回 +0.32，且 8 题反向回落（config-06/11、sales-03/05、reviews-03、cross-09 5→1、social-01、config-06）——文字遵循是概率性的，语义工具是确定性的。
  4. **不可替代③：可辩护证据形态**。A 臂同语料文本重判仅 2.76/32%——产品价值大量存在于结构化 supported_by/as_of 工件而非回复散文，**这正是"可辩护性"卖点本身**：文本判分器看不见的东西恰是交付物。
- **总裁决：取代论不成立**（数据通道缺口+口径执行化差距+证据形态三类不可替代）；**护栏叙事按记账改写**——护城河=数据资产+证据形态+口径执行层；trap/编造两道防线的价值重记为"提示词层资产"。
