## 任务 1：PrismKoubeiWeekly（周日 04:00，Interactive）

cmd（无需管理员；`/sc weekly /d SUN`）：

```bat
schtasks /create /tn "PrismKoubeiWeekly" /tr "cmd /c cd /d C:\Users\<you>\Desktop\Prism-Agent\prism-dashboards && C:\Users\<you>\Anaconda3\python.exe scripts\koubei_weekly_update.py --live >> logs\koubei-weekly.log 2>&1" /sc weekly /d SUN /st 04:00 /f
```

- 时刻依据：给舆情夜跑（现役 PrismSentimentDaily 实触发 03:00，P2-9 更正）留头位；周更跑量分钟级（≈98 页打底 + 增量），重叠无害
- Interactive 形态（仅登录时运行）＝PrismSentimentDaily 同款；无人登录的周日静默跳过 → 由任务 2 补

## 任务 2：PrismKoubeiCatchup（onlogon 登录补跑）

PowerShell（**2026-11-01 实测：schtasks /sc onlogon 报"拒绝访问"——CLI 对登录触发器要提权；Register-ScheduledTask 指定本人用户免管理员，实测成功 State=Ready**）：

```powershell
powershell -NoProfile -Command "Register-ScheduledTask -TaskName 'PrismKoubeiCatchup' -Trigger (New-ScheduledTaskTrigger -AtLogOn -User $env:USERNAME) -Action (New-ScheduledTaskAction -Execute 'cmd.exe' -Argument '/c cd /d C:\Users\<you>\Desktop\Prism-Agent\prism-dashboards && C:\Users\<you>\Anaconda3\python.exe scripts\koubei_weekly_update.py --catchup >> logs\koubei-weekly.log 2>&1' -WorkingDirectory 'C:\Users\<you>\Desktop\Prism-Agent\prism-dashboards') -Settings (New-ScheduledTaskSettingsSet -AllowStartIfOnBatteries -DontStopIfGoingOnBatteries)"
```

- 判定（脚本内，时区固定 Asia/Shanghai）：本地 ≥07:00 且最近成功周更距今 >8 天 → 补跑；日标记 `logs\koubei_catchup_<YYYYMMDD>.done` 幂等；误判无害（预算帽 200 兜底）
- 只判定不跑（排障）：`python scripts\koubei_weekly_update.py --catchup --check`

## 日志与退出码

- dry-run 严格说非零写入：首跑 init_db 建空 collection_runs 表（幂等，此后零写入）——P2-3 如实声明；好处是端点/catchup 提前就绪

- 运行日志：`prism-dashboards\logs\koubei-weekly.log`（追加）；逐系明细：`deploy\data\weekly_progress.jsonl`（每周滚动，保留 8 份）；台账：生产库 `collection_runs` 表
- 退出码：`0`=成功（含 budget_capped）/ `1`=部分车系失败（progress 有 failed 行，可重扫）/ `2`=守卫或环境拦截（看日志 BLOCKED/ERROR 行）/ `3`=无事可做
- 采集失败重试：progress 断点语义——`failed`/`budget_capped` 系下次运行自动重试，`done`/`empty` 跳过
