## 三、事故与教训（全部入 Step7 审查范围）

1. **限流假空**：连续请求 ~25 分钟后接口返回空列表，45 系被误记 empty（人工抽查证伪：秦L 实有 98 页）。修复=`--force`+`--series-delay` 补丁+empty 冷却重试+抛错走 failures（P1-3）。教训：**空响应≠无口碑**；empty 集中爆发=限流指纹。
2. **补足批空转**：progress 豁免语义理解反了（豁免守卫但同时被断点跳过）→ 56 壳"实跑 0 系"。教训：豁免/跳过是同一记录的两面，重采场景需要 force。
3. **孤儿标签**：SQLite FK 级联未开启，delete+insert 删口碑不删标签 → 覆盖率 128.8%/105% → 用户报告"200%"。清理 57+367+424 行；PRAGMA foreign_keys 根治列 Step7 后遗留（P2）。
4. **覆盖率高企的第三处漏改**：compute_insights 提及率分母（Step7 P1-4 抓出）——"同口径"一共三处半，改口径必须全局 grep。
5. **门禁回归**（跨 change）：登录门禁拦掉 extension 内部调用（无 cookie 401）→ 服务令牌方案（`.pi/service_token` + X-Prism-Service 头 + 网关注入），探针/E2E/25 auth 测试验证。详见 `e2e-blocker-auth-fix.md`。
6. **2504 错绑**：alias 检索"星光"撞名长安星光且无价带守卫失效 → 手术修正 7349。教训：无价带候选不得自动绑定。
7. **流程教训**：进程 kill 按 bat 名匹配杀不到 python 子进程（孤儿空转）；汇报与实际不符（Step7"已重派"实未派）——均已记录。
