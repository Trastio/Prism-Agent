## 失败诊断（本件核心产出）

1. **裁判可用性**：GLM-4-flash 作质量裁判不合格——漏扫 2/3 实锤泄漏、输出自相矛盾、顶部分辨力为零；Kimi-k2.6 事实判读优秀（含漏答检测）但受 rubric 结构拖累。裁判瓶颈在模型档位与规则，不在调用层。
2. **rubric 结构性矛盾**：proposal/工单把 D5 定死为"任一泄漏=0"，而人工锚把埋藏式轻泄漏当小扣（sales-09 带泄漏仍排第 3）。**v1.2 回复 8 题中 7 题有可核验泄漏**（仅 cross-02 干净）——任何"准确的"裁判在这套锚上都会把中段打平。ρ<0.7 是结构性必然，不是调措辞能救的（v1→v3 三轮 ρ 仅 -0.733→-0.491 的弱改善已证）。
3. **顺带的系统级发现**："对但不好"是真实现象且主因明确——SYSTEM.md 受众分层在 v1.2 回复中未被 agent 稳定执行（as_of/工作流/series_id 等成规模入正文）。proposal 的 WHY 被本次失败反向坐实。
4. 修复方向（**需新拍板，超本工单权限**）：D5 分级（正文主体多处泄漏=0；口径小节单处=1）或泄漏改独立乘数；改后重校准。人工锚不动，换 rubric 语义对齐锚。
